# 🚀 Hướng dẫn Bài tập: Ứng dụng Todo List với React Hooks

Chào mừng mọi người đến với bài tập thực hành **React Hooks (useState)**. Kho lưu trữ này chứa khung mã nguồn bài tập quản lý công việc (Todo List).

---

## 📋 Yêu cầu bài tập

Mọi người cần hoàn thành các tính năng sau trong file `src/app/page.tsx`:
1. **Hiển thị danh sách công việc** sử dụng `useState` và hàm `.map()`.
2. **Thêm công việc mới** thông qua ô input và nút "Thêm".
3. **Xóa công việc** khi bấm vào nút "Xóa" tương ứng của từng dòng.
4. **Hiển thị tổng số lượng** công việc hiện có.

---

## ⚡ Hướng dẫn thực hiện chi tiết

### Bước 1: Lấy mã nguồn về máy (Clone)
Mở Terminal trên máy tính của bạn và chạy lệnh sau (thay URL bằng repo của bạn hoặc clone trực tiếp từ bản gốc):
```bash
git clone https://github.com/vohoangan207/TodoListApp.git
cd TodoListApp
Bước 2: Cài đặt các gói phụ thuộc (Dependencies)
Bash
npm install
Bước 3: Chạy môi trường phát triển (Development Server)
Bash
npm run dev
Sau đó mở trình duyệt và truy cập: http://localhost:3000
Hướng dẫn nộp bài
Sau khi hoàn thành xong bài tập trên máy của bạn:

Kiểm tra trạng thái thay đổi:

Bash
git status
Thêm file vào danh sách chờ:

Bash
git add .
Lưu lại kèm lời nhắn:

Bash
git commit -m "Hoan thanh bai tap Todo List"
Đẩy code lên GitHub của bạn:

Bash
git push origin main
